# Geo iOS

Личное приложение для macOS, которое управляет симулированной геопозицией
iPhone, подключённого по USB, без jailbreak. Можно выбрать точку, построить
маршрут по дорогам с заданной скоростью или вернуть реальную геопозицию.

## Переносимое приложение

Файл `dist/iOS-Location-Controller-macOS-arm64.zip` содержит готовое
`.app` со встроенным Python-backend и всеми зависимостями. Распакуйте архив и
откройте `iOS Location Controller.app` через Finder. На другом Mac не нужны
Python, Xcode, виртуальное окружение или отдельный установщик.

Сборка предназначена для Mac с Apple Silicon и macOS 13 или новее. Для Intel
Mac нужна отдельная сборка.

На каждом Mac разблокируйте iPhone, подтвердите «Доверять этому компьютеру»,
включите Developer Mode на iPhone и подключите его кабелем USB. Маршруты
строятся через Apple Maps, а при недоступности Apple Maps используется
`routing.openstreetmap.de`. В запасном варианте выбранные начальная и конечная
координаты передаются этому сервису. Маршрут, полученный от OpenStreetMap,
помечается кликабельной ссылкой на авторов и условия использования данных.

ZIP можно прикрепить к GitHub Release, а исходный код хранить в репозитории
`geo-ios`. Каталоги `.venv`, `build` и `dist` исключены из Git. Текущий архив
подписан локальной ad-hoc-подписью и **не нотарифицирован Apple**. После
скачивания с GitHub macOS может показать предупреждение при первом запуске.
Для запуска без такого предупреждения нужны сертификат Developer ID и
нотарификация Apple. Не отключайте защиту macOS полностью.

Встроенный `pymobiledevice3` версии 11.17.0 распространяется по лицензии
GPL-3.0-or-later. Исходники Python-пакета находятся в
`Contents/Resources/backend/_internal/pymobiledevice3`. Реестр зависимостей и
доступные тексты их лицензий включены в
`Contents/Resources/THIRD_PARTY_NOTICES`. Исходный код этой версии приложения
включён в `Contents/Resources/SOURCE`, а точные исходные архивы встроенных
GPL/LGPL-зависимостей — в `Contents/Resources/THIRD_PARTY_SOURCES`. В
репозитории действует лицензия GPL-3.0 из файла `LICENSE`.

## Сборка из исходников

Для сборки на Apple Silicon нужны полный Xcode и Python 3.11 или новее:

```shell
cd geo-ios
python3 -m venv .venv
.venv/bin/python -m pip install -e '.[portable]'
./package_portable.sh
```

Готовые `.app` и `.zip` появятся в каталогах `build/` и `dist/`. Чтобы собрать
только нативное окно без упаковки Python, используйте `./build_macos_app.sh`.
Такая сборка для разработки требует каталог `.venv` рядом с проектом.

Команды CLI:

```shell
./run_locationctl.sh devices --usb
./run_locationctl.sh set 55.7558 37.6173
./run_locationctl.sh clear
./run_locationctl.sh play example-route.gpx
```

Команды `set` и `play` удерживают developer-сессию открытой до Ctrl+C.
После остановки используйте `clear`, чтобы вернуть реальный GPS. Кнопка
«Сбросить на реальное гео» в приложении выполняет ту же операцию.

## Запуск на другом Mac после публикации в GitHub

Есть два способа запустить проект на другом компьютере.

### Рекомендуемый способ: скачать готовое приложение

Используйте этот вариант, если ZIP прикреплён к GitHub Release:

1. Откройте репозиторий на GitHub и скачайте из раздела **Releases** файл
   `iOS-Location-Controller-macOS-arm64.zip`. Также скачайте файл с расширением
   `.sha256`.
2. Откройте Terminal и проверьте архив:

   ```shell
   cd ~/Downloads
   shasum -a 256 -c iOS-Location-Controller-macOS-arm64.zip.sha256
   ```

   Продолжайте только если результат проверки — `OK`.
3. Распакуйте ZIP. Переместите `iOS Location Controller.app` в `Applications`
   или оставьте в другой папке.
4. Подключите iPhone по USB, разблокируйте его и подтвердите «Доверять этому
   компьютеру». На iPhone должен быть включён Developer Mode.
5. Откройте `iOS Location Controller.app`. Если macOS покажет предупреждение
   безопасности, откройте приложение через контекстное меню Finder и выберите
   **Открыть**.
6. Нажмите **Обновить устройства**. В списке должны появиться iPhone и версия
   iOS.
7. В режиме **Точка** нажмите на карте и выберите **Установить геопозицию**.
   В режиме **Маршрут** выберите начало и конец, дождитесь надписи
   **Маршрут готов**, задайте скорость и нажмите **Запустить маршрут**.
8. После работы нажмите **Сбросить на реальное гео**.

Этот ZIP собран для Apple Silicon (`arm64`) и macOS 13 или новее. Для Intel
Mac нужна отдельная сборка. Приложение имеет ad-hoc-подпись и не
нотарифицировано Apple, поэтому при первом запуске Gatekeeper может показать
предупреждение. Не отключайте Gatekeeper полностью.

### Сборка после клонирования исходного репозитория

Используйте этот вариант, если готового ZIP нет или вы хотите собрать
приложение самостоятельно. На другом Mac нужны Apple Silicon, macOS 13 или
новее, полный Xcode и Python 3.11+:

```shell
git clone git@github.com:Plyshkaa/change-geo-ios.git ~/geo-ios
cd ~/geo-ios
python3 -m venv .venv
.venv/bin/python -m pip install -e '.[portable]'
./package_portable.sh
open "build/iOS Location Controller.app"
```

Для публичного репозитория через HTTPS используйте вместо первой команды:

```shell
git clone https://github.com/Plyshkaa/change-geo-ios.git ~/geo-ios
```

На каждом новом Mac сопряжение выполняется отдельно: нужно подтвердить доверие
iPhone к этому Mac и включить Developer Mode. Приложение не переносит данные
сопряжения с другого компьютера.

## Текущая позиция

Кнопка справа сверху пытается получить **геопозицию Mac** и показывает её
маркером на карте. Если macOS не выдаёт координату, приложение сообщает об
этом через 15 секунд. Mac может находиться не там же, где iPhone.

USB developer-сервис, который используется для задания симулированной точки и
маршрута, не возвращает настоящую GPS-координату iPhone. Кнопка «К позиции
iPhone» потребует отдельного iOS-приложения с разрешением CoreLocation,
которое передаст координату на Mac. Например, это можно реализовать в
исходниках собственного TestFlight-приложения.

## Конфиденциальность

В приложении нет аналитики и системы аккаунтов. Для выбора телефона оно
читает имя подключённого устройства, версию iOS и UDID только в память и не
сохраняет эти значения. Созданные GPX-маршруты являются временными и удаляются
после остановки воспроизведения или закрытия приложения. MapKit может
обращаться к серверам Apple, а запасной сервис маршрутизации получает выбранные
начальную и конечную координаты.

## Ограничения и ответственное использование

Утилита предназначена для тестирования собственного приложения и собственных
устройств. Симулированная позиция действует на уровне iOS и может быть видна
другим приложениям, пока developer-сессия активна. Не используйте её для
навигации, экстренных сценариев, систем безопасности или любых решений, где
ошибочная координата способна причинить вред. После теста всегда нажимайте
«Сбросить на реальное гео» и проверяйте позицию в Картах.

Правила стороннего приложения или сервиса могут запрещать подмену координат.
Использование для обхода географических ограничений, антифрода, учёта
