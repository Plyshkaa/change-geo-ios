# Запуск на другом Mac

## Готовый ZIP

1. Скачайте ZIP и файл `.sha256` из GitHub Release. В Terminal проверьте файл:

```shell
cd ~/Downloads
shasum -a 256 -c iOS-Location-Controller-macOS-arm64.zip.sha256
```

2. После результата `OK` распакуйте ZIP и переместите
   `iOS Location Controller.app` в `Applications`
   или оставьте в другой папке.
3. Подключите iPhone кабелем, разблокируйте его и подтвердите доверие Mac.
4. На iPhone включите Developer Mode и перезапустите телефон, если система это
   попросит.
5. Откройте приложение. При предупреждении macOS выберите **Open** в Finder
   через контекстное меню приложения. Не отключайте Gatekeeper целиком.
6. Нажмите **Обновить устройства**. В списке должен появиться iPhone и версия
   iOS. Если список пуст, проверьте кабель, доверие, Developer Mode и что
   телефон разблокирован.
7. В режиме **Точка** выберите место на карте и нажмите **Установить
   геопозицию**. Для маршрута выберите начало и конец, дождитесь надписи
   **Маршрут готов**, задайте скорость и нажмите **Запустить маршрут**.
8. После работы нажмите **Сбросить на реальное гео**.

Приложение в ZIP собрано для Apple Silicon и macOS 13+. Для Intel Mac нужен
отдельный build. На другом Mac нельзя использовать доверие или pairing от
первого Mac: iPhone попросит подтвердить новый компьютер отдельно.

Кнопка справа сверху пытается показать геопозицию **Mac** и добавить маркер.
Она не читает GPS iPhone. USB developer API умеет задавать симуляцию, но не
возвращает исходную координату телефона. Для кнопки «К позиции iPhone» нужно
отдельное iOS-приложение с разрешением CoreLocation, которое передаст координату
на Mac.

## Сборка из исходников

Это нужно только если ZIP не используется. Нужны Apple Silicon, полный Xcode
и Python 3.11+:

```shell
git clone git@github.com:Plyshkaa/change-geo-ios.git
cd geo-ios
python3 -m venv .venv
.venv/bin/python -m pip install -e '.[portable]'
./package_portable.sh
open "build/iOS Location Controller.app"
```
