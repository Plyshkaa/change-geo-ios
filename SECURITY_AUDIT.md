# Перед публикацией

Перед каждым коммитом и GitHub Release проверьте, что в проект не попали:

- `.venv/`, `build/`, `dist/`, логи, дампы и временные GPX-маршруты;
- `*.p12`, `*.p8`, `*.mobileprovision`, `*.key`, `*.pem`, сертификаты и `.env`;
- UDID/серийные номера телефона, имена владельцев, домашние координаты;
- токены GitHub, ключи API, пароли и приватные SSH-ключи.

Команды для локальной проверки:

```shell
cd geo-ios
git status --short
git ls-files | rg -i '(^|/)(\.env|.*\.(p12|p8|key|pem|mobileprovision|cer))$'
rg --hidden --glob '!.venv/**' --glob '!build/**' --glob '!dist/**' \
  -n -e 'BEGIN .*PRIVATE KEY' -e 'ghp_[A-Za-z0-9]+' \
  -e 'github_pat_[A-Za-z0-9_]+' -e 'sk-[A-Za-z0-9]+' \
  -e 'password|passwd|secret|api[_-]?key|client[_-]?secret' .
```

Проверка должна вернуть только ожидаемые слова из документации или пустой
результат. Проверяйте содержимое ZIP отдельно: архив не должен включать
`__MACOSX`, локальные пути `/Users/...`, UDID телефона или ключи.

Если секрет уже попал в Git, простого удаления файла недостаточно: отзовите
секрет у его владельца, затем перепишите историю отдельной процедурой.

## Результат проверки portable-сборки от 23 сентября 2026 года

Проверен файл `dist/iOS-Location-Controller-macOS-arm64.zip`. Актуальная
контрольная сумма каждой сборки записывается рядом с архивом в одноимённый файл
с расширением `.sha256`; этот файл нужно публиковать вместе с ZIP. Фиксировать
хеш в документации нельзя, потому что при пересборке он меняется.

Проверка архива и исходников не обнаружила локальные пути пользователя,
рабочий e-mail, известный UDID и имя iPhone, токены GitHub/OpenAI, приватные
ключи, профили подписи или `.env`. Единственный файл с расширением `.pem` —
публичный набор корневых сертификатов `certifi/cacert.pem`; это не приватный
ключ. Временные GPX создаются с правами `0600`, удаляются при остановке сессии
и очищаются при следующем запуске после аварийного завершения.

Нативный исполняемый файл и backend имеют архитектуру `arm64`. Глубокая
проверка `codesign --verify --deep --strict` проходит. Подпись остаётся
локальной ad-hoc-подписью без Developer ID и нотарификации, поэтому Gatekeeper
может блокировать первый запуск на другом Mac. Для распространения среди
других людей нужна подпись Developer ID и нотарификация Apple.

`pip-audit` не обнаружил известных уязвимостей в установленной цепочке
зависимостей на дату проверки. Это не доказывает отсутствие неизвестных
уязвимостей. Backend не изолирован App Sandbox и включает широкую библиотеку
управления iOS, поэтому запускайте только архив, контрольную сумму которого вы
получили из доверенного источника.

В архив включены уведомления и тексты лицензий для 99 обнаруженных Python-
дистрибутивов, исходники приложения и 13 точных исходных архивов GPL/LGPL-
зависимостей. Это снижает риск нарушения лицензий при передаче ZIP. Перед
GitHub Release сначала опубликуйте соответствующий коммит исходников, затем
прикладывайте собранный из него ZIP и `.sha256`.

Резервный маршрутизатор `routing.openstreetmap.de` получает IP-адрес Mac и
выбранные начальную и конечную координаты по HTTPS. Приложение использует
эфемерную сетевую сессию без дискового кэша, ограничивает обращения одним
запросом в секунду и показывает ссылку на атрибуцию OpenStreetMap. MapKit может
передавать данные маршрута Apple в соответствии с условиями Apple.

## Юридические ограничения

Для личного тестирования собственного TestFlight-приложения на собственном
iPhone риск существенно ниже, чем при использовании подмены в чужих сервисах,
но дать гарантию отсутствия юридических проблем по одним файлам невозможно.
Утилита использует стороннюю реализацию developer-протоколов iOS. Developer
Mode и техническая доступность функции не являются отдельным разрешением Apple
на любой способ и цель её использования.

Не используйте утилиту для обхода антифрода, географических ограничений,
оплаты, контроля посещаемости, правил игр или иных условий сторонних сервисов.
Это может нарушить договор с сервисом, привести к блокировке аккаунта и, в
зависимости от цели и страны, создать правовой риск. Не применяйте
симулированную координату для навигации, экстренных служб и систем
безопасности. Симуляция действует на уровне iOS, поэтому после теста нужно
сбросить её и проверить реальную позицию в Картах.

Основные первичные источники:

- [лицензионное соглашение Xcode и Apple SDK](https://www.apple.com/legal/sla/docs/xcode.pdf);
- [условия и атрибуция OpenStreetMap](https://www.openstreetmap.org/copyright);
- [политика публичного сервера routing.openstreetmap.de](https://routing.openstreetmap.de/about.html);
- [GPL-3.0](https://www.gnu.org/licenses/gpl-3.0.html);
- [исходники и лицензия pymobiledevice3 11.17.0](https://github.com/doronz88/pymobiledevice3/tree/v11.17.0).

Этот отчёт является технической проверкой, а не заключением юриста и не
заменяет анализ законодательства конкретной страны или условий конкретного
сервиса.

## Приватность истории GitHub

Публичная история `main`, начиная с `v0.2.0`, создана с GitHub noreply-адресом.
Перед каждым push проверяйте автора командой `git log -1 --format=fuller`.
Старые недоступные коммиты могли сохраниться в уже сделанных клонах или кэшах,
поэтому однажды опубликованный адрес нельзя гарантированно отозвать у всех
получателей.
